# Modelos

Os modelos são instalados e geridos pelo Ollama, não armazenados neste repositório.
Consulte as páginas oficiais de cada modelo para verificar licença, tamanho,
capacidades e condições de redistribuição antes de usar ou compartilhar.

Exemplo de download pelo Ollama: `ollama pull llama3.2`. O nome é apenas um exemplo;
disponibilidade, licença e requisitos podem mudar.
