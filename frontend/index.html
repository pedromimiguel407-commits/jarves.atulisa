Servidor para este celular

        
O APK funciona como cliente e conecta ao servidor JARVES em outro computador na mesma rede. Hospedar o backend e executar a IA dentro do próprio Android ainda não é suportado; esta configuração não instala nem executa Ollama no telefone.

        
        
        

      

      
Voz do navegador
A voz e a entrada por microfone usam os recursos instalados no seu dispositivo/navegador; elas não alteram a voz do modelo de texto.

        
        
        
        
      

      

        
Fluxo de criação: pesquisar, planejar e executar

        
A pesquisa web é opcional e envia a consulta ao DuckDuckGo. A IA usa o provedor selecionado para planejar; provedores remotos podem cobrar, então escolha Ollama para evitar cobrança por chamada. Revise e confirme antes de executar: as etapas geram respostas/código como texto, não rodam programas nem criam APK/EXE.

        
        
        

          
          
          
          
        

        
Ative “Pesquisa web” nas configurações de IA para liberar a etapa de pesquisa.

        

        
    
        
    
        
        
      
    
      
    
        
    Ajuda para corrigir um erro
    
        
    Cole a mensagem de erro ou código, ou carregue um arquivo de texto/código. O assistente prepara uma sugestão no Chat para você revisar; nada é executado nem alterado automaticamente.
    
        
        
        
        
        
    
      
    
      
    Provedor e conexão
    Para evitar cobranças por uso de API, escolha Ollama local. Baixar modelos consome internet e espaço; a geração usa o hardware do computador/servidor.
    
      
    Modelos locais
    A lista vem do provedor. Modelos Ollama são processados localmente.
    
      
    API key remota (opcional)
    Provedores remotos podem cobrar. O JARVES não cria chaves; a chave salva fica protegida e nunca é exibida novamente.
    GPT-6.1 Sol (`gpt-6.1-sol`) é um modelo de API pago. Só aparece se o provedor remoto o listar.
