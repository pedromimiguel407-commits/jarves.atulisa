Use o JARVES no navegador ou instale como aplicativo web. A IA funciona com Ollama e modelos locais gratuitos no computador que hospeda o servidor.

A instalação como app web depende de o JARVES estar aberto em HTTPS ou em localhost.

Sobre os instaladores nativos APK/AAB, EXE/MSI, AppImage e DEB ainda não foram compilados nem publicados. Esta página não oferece arquivos falsos: por enquanto, use a versão web/PWA ou instale a partir do código-fonte.

Como usar IA local sem pagar API

  1. Instale o Ollama no computador que executará a IA.
  2. Baixe um modelo local, por exemplo ollama pull qwen3.5:4b. O modelo e o espaço em disco são baixados no computador.
  3. Inicie o servidor JARVES nesse computador e abra o endereço mostrado pelo servidor no navegador do seu dispositivo.

O uso local não cobra chamadas de API; requer hardware compatível. Licenças e termos de uso dos modelos variam. O celular não acessa automaticamente o Ollama do PC: ambos precisam estar configurados para a mesma rede/endereço.

O instalador PWA é o próprio site; não é um APK, EXE, AppImage ou pacote nativo.
