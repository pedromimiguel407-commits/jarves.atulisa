Instalação pelo navegador

  1. Abra o JARVES em seu navegador e, se disponível, selecione Instalar JARVES ou “Adicionar à tela inicial”.
  2. Para usar IA local, instale o Ollama no computador que executará o serviço.
  3. O servidor e o Ollama precisam estar ligados e acessíveis pela rede do dispositivo.

A instalação web é a própria interface do site: não é um APK, EXE ou AppImage e não instala Ollama no dispositivo.

Confira as notas e os requisitos na Release antes de instalar um pacote nativo.
