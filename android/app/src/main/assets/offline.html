Bloco de notas local

Estas notas ficam neste aplicativo, neste aparelho. Não são enviadas para nenhum servidor.

Conectar a uma API JARVES

Opcional. Só use se você já tiver um servidor/API disponível. O APK não precisa de computador para abrir o menu, mas a IA generativa do servidor ainda depende de um backend/modelo configurado.

Voz aguardando.

Transparência: esta versão inclui um menu offline, notas locais e ponte para voz do Android. Ela ainda não inclui um modelo generativo offline dentro do APK. Não inicia sozinha ao ligar/reiniciar o aparelho; abra pelo ícone JARVES. O Android limita a abertura automática de telas em segundo plano.
