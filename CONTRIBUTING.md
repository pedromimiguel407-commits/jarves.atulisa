# Como contribuir

1. Abra uma issue descrevendo o problema ou a proposta.
2. Faça alterações pequenas e focadas, mantendo o processamento local como padrão.
3. Execute os testes de Python e a verificação de sintaxe JavaScript descritos no README.
4. Envie um pull request com motivação, alterações e testes realizados.

Não inclua credenciais, dados pessoais, modelos ou arquivos gerados grandes. Informe
as licenças de novas dependências e recursos. Mudanças que adicionem integrações de
rede devem documentar quais dados são enviados e pedir consentimento quando aplicável.
